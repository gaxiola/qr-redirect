How to create a token
1. github.com/settings/personal-access-tokens/new
2. Repository access: Only select repositories → pick qr-redirect
3. Permissions → Contents: Read and write.
About the passphrase
Used to encrypt links.json at rest. The same passphrase is baked into every QR URL (in the #k=… fragment), so QRs work without anyone typing it. Keep a copy somewhere safe — if you lose it and clear this browser, you can't generate new QRs or decrypt existing ones. Reading existing QRs from your scrapbook will still work because the passphrase is inside them.
